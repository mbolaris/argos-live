          Responsiveness

          Output tokens/s measures generation speed. First-token latency measures the wait before an answer starts. Prompt tokens/s measures how quickly it reads input.

          Tested ability

          Fixed, scored tasks measure specific abilities. The quick suite reports correct answers and format errors by category. These are small probes, not an intelligence score or a test of real tool use.

          Your upgrade loop

          1. Test this model. 2. Choose an upgrade for a useful task. 3. Repeat the same suite. 4. Compare gains and regressions. Keep speed and quality separate.

          Live proving ground

          Chat pauses while this local test runs. Watch your AI answer fixed, observable challenges with real-time streamed responses and scored receipts.

          The document trial gives your model eight short original passages. For each it must answer a question, quote the sentence that supports the answer, and say so when the passage does not contain the answer. It also writes a short summary for you to judge. Scoring is automatic and fixed in advance. It runs speed on short and medium prompts first, and qualifies short-document reading only. It says nothing about longer documents or your own files.

          Reboot check

          A small marker file holding only a random identifier and boot ID is written inside Argos folders. After you restart, this page reports whether those folders kept it. That shows the folder was retained. It does not show encryption, and it does not test conversation recall.

          Review model storage
